Micetro architecture and system requirements
############################################

This document is intended to help administrators to install and configure Micetro. It will help administrators to identify strategic servers to install the Micetro components on, as they do not have to be installed on all DNS and DHCP servers in the managed environment.

.. note::
  All Micetro components can be installed on virtual machines.
