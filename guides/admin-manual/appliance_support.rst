Downloading Support Information for Appliances
-----------------------------------------------
To assist in troubleshooting, you may be asked to download a support information file for your appliance. This file contains crucial details about your appliance setup, which can help our support team to diagnose and resolve any issues you may encounter.

**To download support information**:

1. In the **Apoliances** data grid, locate the specific appliance you are troubleshooting. 
2. Use either the :guilabel:`Action` or the Row :guilabel:`...` menu to select :guilabel:`Get support info`. 
3. Select :guilabel:`Download`.
4. Once the download is complete, send the downloaded file to support@bluecatnetworks.com.

.. Note::
   The support information file is packaged as a .tgz archive and contains various text files. To access and view the contents of the support information file, you can use any tool capable of extracting data from .tgz archives.
