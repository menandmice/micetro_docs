Administrating Micetro
======================

This guide provides information and instructions on how to administrate Micetro from the **Admin** page in the Web Application. Refer to the following sections for instructions and information about managing Micetro as the administrator user.

.. _first-login:

Logging in for the first time
-------------------------
When you log into Micetro for the first time as the administrator user, you are prompted to accept the user agreement in the **First Login** wizard. Refer to `BlueCat Legal Agreements <https://bluecatnetworks.com/legal-documents/>`_ for more information about user agreements.

The **First Login** wizard comprises two steps:

1. **First Login** --- To proceed, you must check the :guilabel:`I agree` checkbox. By checking the box, you agree to use Micetro according to the applicable BlueCat user agreement.

2. **Set Password** --- It's highly recommended that you change the administrator password upon first login. For more information about the administrator user, refer to :ref:`administrator`.

.. tip::
   **Strong Passwords**: We recommend using a unique password that contains at least one uppercase letter, one lowercase letter, one number, and one special character. It is also recommended that your password be longer than 12 characters, which increases your password strength.

If you do not agree to the user agreement, you will be logged out of Micetro.
