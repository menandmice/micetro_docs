Editing DHCP Service Properties
-------------------------------
On the :guilabel:`Service Management` tab of the **Admin** page, you can edit a DHCP service's properties, including which agent it uses, the server name and/or address, region, etc. The properties you are able to edit depend on the selected service type.

**To edit service properties**:

1. In the data grid, locate the service whose properties you want to edit.

2. Use either the :guilabel:`Action` or the Row :guilabel:`...` menu to select :guilabel:`Edit service properties`.

3. In the **Edit Service Properties** dialog, make the necessary edits and then select :guilabel:`Save`.
