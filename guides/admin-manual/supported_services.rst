Supported Services
------------------
Micetro supports the following DNS services:

* DNS

  * AuthServe

  * AWS Route 53 (cloud)

  * Azure DNS (cloud)

  * BIND

  * Edge DNS (cloud)

  * Microsoft DNS

  * NS1 (cloud)

  * Micetro DDS Appliance

Micetro supports the following DHCP services:

* DHCP

  * Cisco IOS

  * Cisco Meraki

  * ISC DHCP

  * Kea

  * Microsoft DHCP

  * Micetro DDS Appliance
